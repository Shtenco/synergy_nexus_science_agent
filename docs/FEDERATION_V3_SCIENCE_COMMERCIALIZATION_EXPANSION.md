# Federation V3 — Science → Evidence → Commercialization expansion

This repository absorbs the coordination logic of historical **Part VI** and the science side of **Part VII**.

## Historical domains carried forward

- LENR/cold-nuclear hypotheses;
- fundamental physics candidate theories;
- microelectronics/compute technology;
- pharma/biotech as evidence-gated research domains;
- machine tools/robotics/additive manufacturing;
- AI and cybersecurity;
- commercialization and patent strategy.

## Canonical science workflow

`Problem → Literature/Evidence → Hypothesis → Falsification Plan → Simulation → Experiment Design → Experiment → Reproduction → Evidence Package → TRL Assessment → IP/Commercialization Candidate`.

## Claim vocabulary

`SPECULATION → HYPOTHESIS → MODEL_SUPPORTED → EXPERIMENT_OBSERVED → REPRODUCED → INDEPENDENTLY_REPRODUCED`.

No repository claim may jump stages because a simulation fits historical data.
